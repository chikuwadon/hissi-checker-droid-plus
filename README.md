# 必死チェッカーdroid +

**Hissi Checker Droid Plus**

## 概要

「必死チェッカーdroid +」は、5chのID別書き込みを、**レス・スレ・名前**の3つの視点で確認するAndroidアプリです。オリジナルAPKの機能を出発点に、表示密度、操作性、通信・解析処理の改善を進めています。

- **オリジナルAPK v1.5を基準とした独立再構築版**です。
- プロジェクト名は **Hissi Checker Droid Plus**（リポジトリ名：`hissi-checker-droid-plus`）、アプリの表示名は **必死チェッカーdroid +** です。

## 主な機能

| 分類 | 内容 |
| :-- | :-- |
| **5ch検索** | 板・日付・IDを指定して必死チェッカーの結果を表示。`ID:` / `ID：` 付きの入力も受け付けます。 |
| **板一覧** | [5ch公式メニュー](https://menu.5ch.io/bbsmenu.html)を参照し、**カテゴリ → 板**の順で選択。公式JSONを優先し、取得失敗時はHTML・保存データなどへフォールバックします。 |
| **結果の3タブ** | レス / スレ / 名前。**下線式タブ**をタップ、または左右にスワイプして切り替えます。 |
| **レス一覧** | 余白と装飾を抑えたダークUI。大きなカードは使わず、細い区切り線でレスを表示します。 |
| **スレ一覧** | 同じスレッドをURL末尾のレス番号の違いに左右されず集約します。 |
| **レス操作** | レスをタップすると中央に操作ダイアログを表示。常設のコピー・共有ボタンは置きません。 |
| **ChMate連携** | 対応リンク・テキスト共有（`text/*`）から結果画面を直接起動し、戻る操作で呼び出し元へ戻る構成です。 |
| **エッヂ（試験対応）** | URL認識、専用解析処理、WebViewとHTTPのCookie共有・診断機能を実装。ただし、**実サイトからのレス取得は未確認・アクセス拒否の問題が残っています**。 |

### レスの操作・コピー

レスをタップすると、以下の操作を選べます。

| 操作 | コピーする内容 |
| :-- | :-- |
| スレを開く | 対応スレッドを開きます。 |
| **スレタイ+全体コピー** | スレタイ → レスURL → **レス番号から始まる投稿情報** → 本文 |
| **全体コピー** | **レス番号から始まる投稿情報** → 本文 |
| **追加スレタイ+全体コピー** | 現在のクリップボードに、スレタイ・URLを含む内容を追記 |
| **追加全体コピー** | 現在のクリップボードに、投稿情報と本文を追記 |
| **IDコピー** | IDの値のみコピー（`ID:` は付けません）。 |
| **リンクコピー** | レスURLをコピー |

コピーした文章では、空のメール欄を `[]` として表示せず、不要な区切り文字・連続スペースを整理します。Android 13以降はOS側のクリップボード通知との二重表示を抑制します。

## UIの方針

- ダークテーマを基準に、アクセントカラーは **`#00B8AF`**。タイトルの「droid +」にも適用します。
- タブは**選択中の項目にだけ下線**を表示。塗りつぶしや枠線付きのタブにはしません。
- レス表示は細い区切り線とコンパクトな余白を使い、画面内の情報量を優先します。
- ダイアログは**画面中央・角丸・テーマに沿った配色**に統一。下から出るシート型は使いません。
- アイコンはオリジナルの顔文字を基準に、「+」と `HISSICheckerDroid+` を加えた構成とします。

### ローカルビルド

JDK 17、Android SDK 36、Gradle 9.8.2が必要です。

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

生成されたデバッグAPKは `app/build/outputs/apk/debug/` に保存されます。Gradle Wrapperは現時点で同梱していません。

Privateリポジトリでは、mainのGitHub Actionsでビルド・検証しています。**Release・一般公開は実施していません**。

## エッヂ MHT の解析について

2026年10月22日にブラウザ保存された実際のエッヂ必死チェッカーページを調査し、HTMLの `Shift_JIS`、`.box.content > .post`、`.r-head` と投稿本文のテキストノード構造を確認しました。保存ページのレス65件・スレ7件を参考に**匿名化した構造テスト**を用意しています。実データをGitHub上へ登録していません。

HTTP応答からステータスコード・Content-Type・文字コード・リダイレクト回数・Cookie送信の有無を、IDや本文を含まずに診断できるようにしています。ブラウザでは表示できてもアプリにHTTP 403が返る可能性があり、**正常取得を保証するものではありません**。
