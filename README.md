## 概要

5chとエッヂのID別書き込み検索・閲覧、およびスレタイによる過去ログ検索に対応する非公式Androidアプリである。レスの一覧表示、投稿状況の集計、検索履歴、お気に入り、掲示板アプリとの連携に対応する。

オリジナルの「必死チェッカーdroid」v1.5を参考に、新たに開発したアプリです。

> 開発中のv1.2.0では、Kyodemo / その他の掲示板と検索結果の保持を追加しています。正式版はv1.1.0です。

## 主な機能

| 機能 | 内容 |
| --- | --- |

| エッヂ検索 | 板・IDによる検索、日付指定あり / 日付指定なしの切り替え |
| 板一覧 | カテゴリ別の板選択、板名・板コード・カテゴリ名での検索、板のお気に入り、オフライン用板一覧 |
| 過去ログ検索 | エッヂの過去ログ（3代目）、Kyodemo / エッヂ、Kyodemo / 5ch、ぬこ / 5chのスレタイ検索、詳細条件、ページ指定、検索履歴 |
| 検索結果 | 「レス」「スレ」「名前」の3タブ、タップ・左右スワイプによる切り替え |
| 投稿情報 | 投稿件数、スレ別・名前別の件数、時間帯別の投稿グラフ |
| レス操作 | タップで各種コピー・スレを開く、長押しでテキストの範囲選択とコピー |
| 履歴・お気に入り | 履歴保存件数100～10,000件（100件単位）・無制限、板名・ID・日付での絞り込み、並べ替え、複数選択削除 |
| 外部連携 | ChMate・Haiagaruなどの対応アプリやブラウザでスレッドを開く、エッヂのID検索リンクをアプリで受け取る |
| 表示設定 | ダーク / ライト / システムテーマ、タブ切替アニメーションのON/OFF、ナビゲーション項目の表示設定、過去ログ検索欄の上下配置 |

## 使い方

### 5chを検索する

1. 板IDを入力するか、「カテゴリから板を選択」から板を選びます。
2. 検索日とIDを指定して「IDを検索」を押します。
3. 日付が分からない場合は「指定なし（直近7日）」を選びます。

日付指定なしでは、日本時間の当日から過去6日までを新しい順に調べ、最初に見つかった日付の結果を開きます。全期間を検索したり、7日分の結果をまとめて表示したりする機能ではありません。

### エッヂを検索する

1. 板ID（例：`liveedge`）と検索したいIDを入力します。
2. 特定の日を調べる場合は検索日を指定し、指定しない場合は「日付指定なし」を選びます。
3. 「IDを検索」を押します。

日付指定ありでは、投稿日時とIDを確認し、条件に合うレスを表示します。日付指定なしでは、検索サイトが返した候補スレッドの結果を開きます。サイトの検索対象すべてを網羅するものではありません。

必死チェッカーのURLが分かっている場合は、ホーム画面下部の入力欄から直接開くこともできます。ChMate / HaiagaruからエッヂのID検索を開く操作にも対応しています。一般検索ページやスレッドページは対象外です。

### 検索結果を見る

検索結果には次の3つのタブがあります。タップでも左右スワイプでも切り替えられます。切り替え時のスライドアニメーションは設定画面からON/OFFを変更できます。

- **レス**：投稿を一覧表示。タップすると、スレを開く、全体コピー、本文コピー、追加コピー、リンクコピーを選べます。本文などを長押しすると、範囲を選択してコピーできます。
- **スレ**：書き込みのあるスレッドをまとめて確認できます。
- **名前**：投稿者名ごとに書き込みを確認できます。

投稿件数や時間帯別のグラフなども表示できます。表示内容は検索先から取得できた情報によって異なります。

下部ナビゲーションからホーム、結果、過去ログ、履歴、お気に入り、設定へ移動できます。結果画面の右上メニューでは外部ブラウザ、URL・ID・書き込みスレのコピー、表示中のレスの一括コピーを利用できます。エッヂでは書き込み分析も確認できます。

### 過去ログ検索

下部ナビゲーションの「過去ログ」から検索サービスを選び、スレタイを入力して検索します。Kyodemo / 5chでは板を指定します。ぬこ / 5chでは全板検索または板指定を選べます。ホーム画面と板のお気に入りを共有します。最後に選択した検索サービスとサービスごとの板はアプリ再起動後も保持します。URLコピーは元スレッドのURLを使用します（公式板一覧で解決できない場合はコピーできない旨を表示）。

| サービス | 詳細条件 |
| --- | --- |
| エッヂの過去ログ（3代目） | 除外ワード、レス数範囲、ソート、日付範囲、半角全角あいまい検索（サイト提供条件に依存） |
| Kyodemo / エッヂ・5ch | 除外ワード、日付範囲、ソート、レス数 |
| ぬこ / 5ch | 全板・板指定、完全一致、外部板も検索 |
| Kyodemo / その他の掲示板（開発中） | まちBBS、ふたばちゃんねる、したらば、おーぷん2ch、いつもch、やる夫、JPNKN、ぷにぷに、オルグ、その他の板指定検索 |

結果のアプリ内表示、ページ移動・ページ指定、長押しコピー、外部ブラウザに対応します。詳細条件・外部ブラウザの右側の「Aa」から検索結果の文字サイズを70～160%（5%単位、初期値100%）でリアルタイム調整でき、再起動後も保持します。検索キーワード履歴は個別または一括削除できます。サイト側の取得上限や検索対象に依存するため、全期間・全スレッドの取得を保証するものではありません。

### 検索結果の保持

設定の「検索結果を保持」は初期状態でONです。ID検索と過去ログ検索の直近の結果を端末内に保存し、再起動後に各画面から復元できます。戻る操作では外部アプリから起動した場合も表示したタブの履歴を逆順にたどり、履歴が尽きた場合は終了します。起動時は最後に表示した下部ナビゲーションのタブに戻ります（保存結果がない場合はホーム）。OFFにすると保存済みの検索結果を削除します。検索履歴やお気に入りは削除されません。

### 履歴とお気に入り

ID検索履歴の保存件数は初期値100件で、設定から100～10,000件（100件単位）または無制限に変更できます。板名・ID・日付による絞り込み、新しい順・古い順・板名順・検索日順、個別削除・複数選択削除に対応しています。

検索結果のお気に入りは履歴と別に管理されるため、履歴を削除しても残ります。5chの板のお気に入りも利用できます。

## 板一覧とオフライン利用

5chの板一覧は公式メニューから取得し、端末にキャッシュします。通信できない場合でも、キャッシュやアプリ内蔵の板一覧から板を選択できます。板IDを直接入力することもできます。

## 外部アプリとの連携

5chとエッヂのスレッドを、ChMateまたはHaiagaruパッチを適用したChMateで開けます。両方インストールされている場合は開くアプリを選択できます。選択画面の「次回から確認しない」をチェックすると、次回から5chとエッヂの両方に同じ設定が適用されます。片方のみの場合は直接起動します。

設定画面の「スレの開き方」から、「毎回選択」への切り替えや使用するアプリの変更ができます。「リンクの開き方」は別の設定です。Haiagaruのパッケージ名を標準設定から変更した場合、専用の選択肢には表示されません。

### ChMate / HaiagaruのID長押し検索

ChMate / Haiagaruの「検索に使うURL(追加用)」に本アプリを登録すると、レスのIDを長押しして直接ID検索を実行できます。

#### 登録方法

1. ChMate / Haiagaruの「設定」→「実験的」→「検索に使うURL(追加用)」を開きます
2. 以下の1行を追加し、「OK」を押します

```text
必死チェッカーdroid+ hissi:{$host}/{$bbs}/{$id}?date={$date[yyyyMMdd]}
```

3. スレッド内のレスのIDを長押しし、「必死チェッカーdroid+」を選択します

5ch・エッヂのどちらにも対応しており、選択したレスの投稿日を指定して検索します。

日付を指定せずに検索したい場合は、代わりに以下のURLを登録してください。

```text
必死チェッカーdroid+ hissi:{$host}/{$bbs}/{$id}
```

日付指定なしの場合、5chは当日から過去6日までの直近7日間を検索し、エッヂは日付を指定せずに検索します。

既存のURL共有と通常のID検索にも対応しています。対応するホスト以外からのリンクからは検索を行いません。

## 利用上の注意

検索や書き込み分析には外部サイトへの接続が必要です。サイトの仕様変更、アクセス制限、通信状況によって一部の結果を取得できない場合があります。

履歴、お気に入り、設定は端末内に保存されます。通信先やデータの取り扱いについては[プライバシーポリシー](PRIVACY.md)をご確認ください。

不具合・改善要望はGitHub Issuesで受け付けています。報告にはAndroidとアプリのバージョン、再現手順などをご記載ください。個人情報やCookieなどの情報は公開しないでください。

## 開発

アプリ本体のソースコードはKotlinへの移行を完了しています（単体テストの一部はJava）。ソースからビルドする場合は、JDK 17、Android SDK 37.0（compileSdk 37、targetSdk 36）、Android Gradle Plugin 9.5.1、Gradle 9.9.2が必要です（Gradle Wrapperは同梱していません）。

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
