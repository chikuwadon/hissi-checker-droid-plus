# 必死チェッカーdroid +

**Hissi Checker Droid Plus**

</div>

## 概要

5chとエッヂのID別書き込みを検索・閲覧できるAndroidアプリです。レスの一覧表示や投稿状況の集計、検索履歴、お気に入り、掲示板アプリとの連携に対応しています。

オリジナルの「必死チェッカーdroid」v1.5を参考に、新たに開発したアプリです。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 5ch検索 | 板・日付・IDを指定した検索、日付指定なし（直近7日）の検索 |
| エッヂ検索 | 板・IDによる検索、日付指定あり / 日付指定なしの切り替え |
| 板一覧 | カテゴリ別の板選択、板のお気に入り、オフライン用板一覧 |
| 検索結果 | 「レス」「スレ」「名前」の3タブ、タップ・左右スワイプによる切り替え |
| 投稿情報 | 投稿件数、スレ別・名前別の件数、時間帯別の投稿グラフ |
| レス操作 | スレを開く、全体コピー、本文コピー、追加コピー、リンクコピー |
| 履歴 | 直近100件の検索履歴、お気に入り、並べ替え、複数選択削除 |
| 外部連携 | ChMateなどの対応アプリやブラウザでスレッドを開く |
| 表示設定 | ダーク / ライト / システムテーマ、コンパクトな一覧表示 |

## 使い方

### 5chを検索する

1. 板IDを入力するか、「カテゴリから板を選択」から板を選びます。
2. 検索日とIDを指定して「IDを検索」を押します。
3. 日付が分からない場合は「指定なし（直近7日）」を選びます。

日付指定なしでは、日本時間の当日から過去6日までを新しい順に調べ、最初に見つかった日付の結果を開きます。全期間を検索したり、7日分の結果をまとめて表示したりする機能ではありません。

### エッヂを検索する

1. 板ID（例：`liveedge`）と検索したいIDを入力します。
2. 特定の日を調べる場合は検索日を指定し、指定しない場合は「日付指定なし」を選びます。
3. 「IDを検索」を押します。

日付指定ありでは、投稿日時とIDを確認し、条件に合うレスを表示します。日付指定なしでは、検索サイトが返した候補スレッドの結果を開きます。サイトの検索対象すべてを網羅するものではありません。

必死チェッカーのURLが分かっている場合は、ホーム画面下部の入力欄から直接開くこともできます。

### 検索結果を見る

検索結果には次の3つのタブがあります。タップでも左右スワイプでも切り替えられます。

- **レス**：投稿を一覧表示。レスをタップすると、スレを開く、全体コピー、本文コピー、追加コピー、リンクコピーを選べます。
- **スレ**：書き込みのあるスレッドをまとめて確認できます。
- **名前**：投稿者名ごとに書き込みを確認できます。

投稿件数や時間帯別のグラフなども表示できます。表示内容は検索先から取得できた情報によって異なります。

右上メニューからは、検索履歴、ホーム画面へ戻る、外部ブラウザで開く、IDのコピーなどを利用できます。エッヂでは、サイトが提供する書き込み分析も確認できます。

### 履歴とお気に入り

検索履歴は直近100件まで保存されます。並べ替え、個別削除、複数選択による削除に対応しています。

検索結果のお気に入りは履歴と別に管理されるため、履歴を削除しても残ります。5chの板のお気に入りも利用できます。

## 板一覧とオフライン利用

5chの板一覧は公式メニューから取得し、端末にキャッシュします。通信できない場合でも、キャッシュやアプリ内蔵の板一覧から板を選択できます。板IDを直接入力することもできます。

## 外部アプリとの連携

スレッドを開く際はChMateとの連携に対応しています。ChMateが利用できない場合は他の対応アプリを探し、必要に応じてブラウザで開きます。

ホーム画面右上のメニューでは、テーマやリンクの開き方を変更できます。実際の連携動作は、利用するアプリの対応状況によって異なります。

## 動作環境

- Android 8.0以降
- バージョン：1.0.0
- アプリID：`com.chikuwadon.hissidroidplus`

## 利用上の注意

検索や書き込み分析には外部サイトへの接続が必要です。サイトの仕様変更、アクセス制限、通信状況によって一部の結果を取得できない場合があります。

履歴、お気に入り、設定は端末内に保存されます。通信先やデータの取り扱いについては[プライバシーポリシー](PRIVACY.md)をご確認ください。

不具合・改善要望はGitHub Issuesで受け付けています。報告にはAndroidとアプリのバージョン、再現手順などをご記載ください。個人情報やCookieなどの情報は公開しないでください。

## 開発

本アプリはJavaで開発しています。ソースからビルドする場合は、JDK 17、Android SDK 36、Gradle 9.8.2が必要です（Gradle Wrapperは同梱していません）。

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
