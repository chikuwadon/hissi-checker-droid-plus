# 必死チェッカーdroid +

**Hissi Checker Droid Plus**

`v1.0.0` · `Android 8.0+` · `Java 17`

</div>

---

## 概要

必死チェッカーdroid + は、5chとエッヂのID別書き込みを検索・閲覧するAndroidアプリです。
コード・画面・アイコンを独自に制作した非公式アプリです。「必死チェッカーdroid」の公式更新版ではありません。

## 主な機能

| 機能 | 内容 |
| :-- | :-- |
| 5ch | 板・日付・ID検索、日付指定なし（直近7日）、公式メニューのカテゴリ別板選択 |
| エッヂ | 日付指定／日付指定なしのID検索、レス・スレッド一覧、サイト提供の書き込み分析 |
| 一覧 | レス・スレ・名前の3タブ。タップと左右スワイプで切り替え |
| 集計 | 投稿件数、スレ別・名前別の件数、取得可能な時間帯別投稿グラフ |
| レス操作 | スレを開く、全体／本文／リンク／IDのコピー、追加コピー |
| 履歴 | 直近100件の検索履歴、独立したお気に入り、並べ替え・削除 |
| 他アプリ連携 | ChMateへのスレッド直接起動。未導入時は対応アプリを検索し、なければブラウザで開く |
| 表示 | ダーク・ライト・システムテーマ、密度重視の一覧、中央配置の操作ダイアログ |

結果画面の右上メニューには「検索履歴」「ホーム画面に戻る」「検索結果を外部ブラウザで開く」などを配置しています。

検索日は、5chでは指定日または直近7日の範囲を選択できます。日付指定なしの5ch検索は板・IDを使って日ごとに最大7回確認し、最初に見つかった日付の結果を開きます（全期間検索ではありません）。エッヂでは検索日に加えて「日付指定なし」も選べます。日付指定ありのエッヂ検索では、取得したレスの日付・IDを照合して別の日付の投稿を誤表示しないようにします。

5chの板一覧は端末内のキャッシュを優先し、必要に応じて公式メニューから取得します。どちらも利用できない場合は、5ch公式メニューを基に独立生成した内蔵のオフライン板一覧を表示します。板名を直接入力する方法も利用できます。原作アプリから抽出した板一覧は同梱していません。

### 外部アプリ連携

ChMateがインストールされている場合は、動作確認済みのスレッド表示Activityを明示して開きます。ChMateがない場合は、エッヂURLを受け付ける他の掲示板アプリを検索し、候補が1件なら直接起動、複数なら選択画面、候補がなければ既定のブラウザを利用します。

外部アプリの対応状況は、各アプリのIntent設定・バージョンとAndroidのパッケージ可視性設定に依存します。

### エッヂの動作状況

エッヂの解析処理は取得したMHTなどを用いて検証していますが、サイト側のHTTP 403や認証・アクセス制限によって正常取得できない場合があります。書き込み分析はサイト自身が提供する結果を表示し、アプリ独自のAI分析は行いません。

**ビルドや単体テストの成功は、すべての端末での通信・実機動作を保証するものではありません。**

## ビルドとテスト

JDK 17、Android SDK 36、Gradle 9.8.2が必要です。Gradle Wrapperは同梱していません。

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

開発用APKは `app/build/outputs/apk/debug/` に、配布用にビルドしたAPKは `app/build/outputs/apk/release/` に生成されます。配布用APKには固定署名が必要です。GitHub Actionsではビルド、Lint、署名検証を実施します。検証用成果物は正式なGitHub Releaseではありません。

署名鍵の安全な管理については [署名設定](docs/SIGNING.md) を参照してください。**秘密鍵・キーストア・パスワードをコミットしないでください。**

## データ・プライバシー

検索履歴やお気に入りは端末内に保存されます。検索・分析・外部リンク操作では、hissi.org、kyodemo.net、5chの板メニューなど、指定した外部サービスへアクセスします。サイト側の仕様変更やアクセス制限によって利用できない機能があります。

通信先、Cookie、保存内容、HTTP通信上の注意は [プライバシーとデータの取り扱い](PRIVACY.md) に記載しています。
