# 必死チェッカーdroid +

**Hissi Checker Droid Plus**

Android 8.0以降 / v1.0.0 / Java 17

5chとエッヂのID別書き込みを検索・閲覧する非公式Androidアプリです。レス、スレッド、投稿者名ごとの表示に加え、投稿件数の集計、コピー、履歴、外部掲示板アプリとの連携に対応しています。

コード、画面、ランチャーアイコンは独自に制作しています。「必死チェッカーdroid」の公式更新版ではありません。また、5ch、エッヂ、hissi.org、ChMateの公式アプリではありません。

## 主な機能

| 分類 | 内容 |
| --- | --- |
| 5ch | 板・日付・ID検索、日付指定なし（直近7日）の検索 |
| エッヂ | 板・ID検索、日付指定と日付指定なしの切り替え |
| 板一覧 | 5ch公式メニューのカテゴリ別表示、キャッシュ、オフライン用一覧、板のお気に入り |
| 検索結果 | レス / スレ / 名前の3タブ、タップと左右スワイプで切り替え |
| 投稿情報 | 投稿件数、スレ別・名前別の件数、取得可能なデータに基づく時間帯グラフ |
| コピー | 全体コピー、本文コピー、追加コピー、リンクコピー、IDコピー |
| 履歴 | 直近100件の検索履歴、独立した検索結果のお気に入り、並べ替えと削除 |
| 外部連携 | ChMate、他の対応掲示板アプリ、ブラウザでスレッドを開く |
| 表示設定 | ダーク / ライト / システムテーマ、省スペースの一覧と中央配置の操作ダイアログ |

## 使い方

### 5chのID検索

1. ホーム画面の「5ch」で板IDを入力するか、「カテゴリから板を選択」で板を選びます。
2. 検索日とIDを指定し、「IDを検索」を押します。
3. 日付が不明な場合は「指定なし（直近7日）」にチェックを入れます。

「指定なし（直近7日）」では、**日本時間の当日から過去6日までを新しい順に調べ、最初に見つかった日付の結果を開きます**。全期間検索ではなく、7日分をまとめて表示する機能でもありません。通信に失敗した場合は、調査していない日付も含めて「該当なし」と断定しないようにしています。

検索したページがHTTP 404を返した場合は、ページが見つからなかった旨を表示します。ただし、404だけで投稿の存在を完全に判断できるものではありません。

### エッヂのID検索

1. ホーム画面の「エッヂ」に板ID（例：`liveedge`）とIDを入力します。
2. 特定の日を調べる場合は検索日を選び、日付を絞らない場合は「日付指定なし」を選びます。
3. 「IDを検索」を押します。

日付指定検索では、**取得した投稿の日時とIDを照合し、指定日と異なるレスを表示しない**ようにしています。日付が確認できないレスも、日付指定検索の一致結果として扱いません。

日付指定なし検索では、サイトが返した候補スレッドから結果を開きます。サイト全体の過去ログを網羅する保証はなく、複数スレッドの投稿を一度に集計する機能ではありません。

エッヂの必死チェッカーURLを持っている場合は、ホーム画面下部のURL欄から直接開くこともできます。

### 検索結果を閲覧・操作

- **レス**：取得したレスを一覧で確認します。レスをタップすると、「スレを開く」「全体コピー」「本文コピー」「追加コピー」「リンクコピー」を選べます。
- **スレ**：取得したレスをスレッド単位で確認します。
- **名前**：投稿者名単位で整理して確認します。
- **集計**：レス数やスレ別・名前別の件数、時間帯グラフを表示します。グラフは集計部分をタップして開閉できます。
- **右上メニュー**：検索履歴、ホーム画面に戻る、外部ブラウザで開く、IDコピー、表示中のレスの一括コピーなどを利用できます。

エッヂでは、サイトが提供する「書き込み分析」をアプリ内から開けます。分析結果を独自のAIで生成するものではありません。

### 履歴とお気に入り

検索結果は直近100件まで履歴に記録され、履歴画面から再度開けます。日時や板などで並べ替え、個別削除・複数選択削除にも対応します。**検索履歴と検索結果のお気に入りは別管理**のため、通常の履歴削除ではお気に入りを削除しません。

5chの板を保存する「板のお気に入り」は、検索結果のお気に入りとは別機能です。

## 板一覧とオフライン動作

5chの板一覧は、端末にキャッシュした公式メニューを優先し、必要に応じてオンラインで再取得します。両方が使えない場合は、アプリに同梱したオフライン版の板一覧を使用します。板IDを直接入力する方法も利用できます。

同梱データは、2026年10月23日に5ch公式BBSMENUを基に独立生成したスナップショットです（**933板 / 49カテゴリ**）。最新の板構成と異なる場合があります。原作APKから抽出した板データは使用していません。生成方法と更新方針は[オフライン板一覧](docs/BOARD_MENU_SNAPSHOT.md)に記載しています。

## 外部アプリ連携と画面設定

ChMateが利用できる場合は、対応するスレッド表示画面にリンクを引き渡します。利用できない場合は他の対応アプリを検索し、候補の数に応じて直接起動またはアプリ選択画面を表示します。対応アプリが見つからない場合はブラウザで開きます。

ホーム画面右上のメニューから、テーマ（ダーク / ライト / システム）とリンクの開き方（連携モード / 単独アプリモード）を設定できます。実際の連携先や開ける投稿番号は、外部アプリの対応状況にも依存します。

## ビルドとテスト

ソースからビルドする場合はJDK 17、Android SDK 36、Gradle 9.8.2が必要です。Gradle Wrapperは同梱していないため、Gradleを別途用意してください。

```bash
gradle --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APKの出力先は`app/build/outputs/apk/debug/`です。Release APKは`app/build/outputs/apk/release/`に出力されますが、正式配布版と同じ署名を付けるには別途キーストアが必要です。**署名鍵、キーストア、パスワードをリポジトリに登録しないでください。**

GitHub Actionsでは、単体テスト、Lint、署名付きRelease候補のビルドと署名検証、Android 8 / 14 / 16エミュレーターでの基本動作・上書き更新テストを実施しています。自動テストの成功は、すべての実機や外部サービスでの動作を保証するものではありません。

## 通信とプライバシー

検索や板一覧取得などの操作に応じて、hissi.org、menu.5ch.io、kyodemo.netなどへアクセスします。hissi.orgは互換性のため暗号化されないHTTPで通信する場合があります。外部サイトの仕様変更、HTTP 403などのアクセス制限、HTML構造変更によって一部の機能を利用できないことがあります。

検索履歴、お気に入り、表示設定、板メニューのキャッシュは端末内に保存します。アプリ独自のアカウント登録、同期サービス、広告・解析SDKは実装していません。詳しくは[プライバシーとデータの取り扱い](PRIVACY.md)を参照してください。

不具合報告時にはAndroidとアプリのバージョン、対象機能、再現手順を記載してください。ID、Cookieなどの情報を公開Issueに掲載しないでください。
