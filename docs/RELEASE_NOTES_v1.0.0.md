# 必死チェッカーdroid + v1.0.0

5chとエッヂのID別書き込みを検索・閲覧できるAndroidアプリです。検索結果をレス、スレッド、投稿者名ごとに確認し、投稿状況の集計やコピーも行えます。

## 検索

**5ch**
- 板・日付・IDを指定して検索できます。
- 日付が分からない場合は「指定なし（直近7日）」を選べます。当日から過去6日間を新しい順に調べ、最初に見つかった日付を開きます。
- カテゴリ別の板一覧、板のお気に入り、キャッシュとオフライン用板一覧に対応しています。

**エッヂ**
- 日付指定あり / 日付指定なしのID検索を選択できます。
- 日付を指定した検索では、投稿日時とIDを照合し、別の日付の投稿が表示される問題を修正しました。
- 必死チェッカーのURLを直接開くこともできます。

## 閲覧・操作

- 「レス」「スレ」「名前」の3タブで検索結果を確認。左右スワイプで切り替えられます。
- 投稿件数、スレ別・名前別の集計、時間帯別の投稿グラフを表示します。
- レスをタップすると、スレを開く、全体コピー、本文コピー、追加コピー、リンクコピーを選べます。
- 直近100件の検索履歴、お気に入り、並べ替え、複数選択による削除に対応しています。
- ChMateや他の対応掲示板アプリ、ブラウザでスレッドを開けます。
- エッヂの書き込み分析をアプリ内から確認できます。
- ダーク / ライト / システムテーマに対応しています。

## 主な改善点

- エッヂで指定日と異なる投稿が検索結果に表示される問題を修正。
- 5chで対象ページが見つからない場合の案内を改善。
- 検索結果の読み込み、外部アプリ連携、一覧表示、画面操作を改善。

## 動作環境

**Android 8.0以降**に対応しています。

検索結果や分析情報の取得は外部サイトの状態に依存します。サイトの仕様変更やアクセス制限によって一部の機能が利用できない場合があります。5chの日付指定なし検索は直近7日間が対象です。
