# 必死チェッカーdroid + v1.0.0

## 主な機能

- 5chとエッヂのID検索と、レス・スレッド・名前別の閲覧
- カテゴリ別の5ch板一覧、オフライン板一覧、履歴とお気に入り
- 投稿件数集計、時間帯別投稿グラフ
- レスの全文・本文・リンクのコピー、追加コピー
- ChMateと他の対応掲示板アプリへのスレッド連携
- ライト／ダーク／システムテーマ

## 改善

- 検索結果の表示、通信エラー処理、外部アプリ連携、画面操作を改善
- WebViewのファイルアクセスを制限
- 平文HTTP接続はhissi.org関連ホストに限定

## 動作環境

Android 8.0以降。

本アプリは5ch・エッヂ・ChMateの公式製品ではありません。外部サイト側の認証・アクセス制限や仕様変更により利用できない機能があります。

## v1.0.0候補の追加修正：エッヂ検索日付

エッヂのID検索で、選択日付と異なる投稿が検索結果として表示される問題を修正。サイトからの候補スレッドについて実際の投稿日時・IDを検証し、一致したレスだけを表示します。日付が確認できないレスも、日付指定検索の結果としては表示しません。外部アプリから開いた既存の必死チェッカーURLの操作方法は維持します。

## 日付指定なし検索と取得エラー表示

- 5ch：検索日欄から「指定なし（直近7日）」を選択可能。最大7日分を日ごとに照合し、見つかった日付で結果を開く。全期間検索ではなく、一部の通信が失敗した場合は「結果なし」と断定しない。
- エッヂ：「日付指定なし」では公式サイトのID検索を日付範囲なしで実行し、結果に含まれるスレッドの実日時から開く際の検索日を設定する。日付指定ありの厳密チェックはそのまま維持。
- 5ch：検索結果URLがHTTP 404のとき、「レスを取得できませんでした」だけでなくページが見つからない旨と考えられる理由を表示する。
