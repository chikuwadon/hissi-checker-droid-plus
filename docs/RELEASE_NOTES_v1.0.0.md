# 必死チェッカーdroid + v1.0.0

5chとエッヂのID別書き込みを、Androidで検索・閲覧するための非公式アプリです。板・日付・IDによる検索に加え、レスの一覧、スレッド別・名前別の整理、コピー、履歴、外部掲示板アプリとの連携を搭載しています。

## 検索機能

### 5ch

板と日付、IDを指定した検索に対応しています。日付が分からない場合は、**「指定なし（直近7日）」**を選択できます。日本時間の当日から過去6日までを新しい順に調べ、最初に投稿が見つかった日付を開きます。

これは全期間検索ではなく、7日分をまとめて表示するものでもありません。検索途中に通信障害が発生したときは、結果がないと断定せずエラーを表示します。

板選択画面では、5ch公式メニューをカテゴリ別に表示できます。端末内のキャッシュに加え、公式メニューから独立生成した**オフライン板一覧**を同梱しているため、通信が利用できない場合でも板を選択できます。板IDを直接入力することも可能です。

### エッヂ

**日付指定あり / 日付指定なし**のID検索を切り替えられます。日付を指定した場合は、取得したレスの投稿日時とIDを確認し、別の日付の投稿が表示される問題を修正しました。

日付指定なし検索では、サイトの検索結果から候補スレッドを開きます。サイト側が提供する検索結果に依存するため、全期間の書き込みを網羅するものではありません。必死チェッカーURLを直接貼り付けて開く機能も利用できます。

## 検索結果の閲覧と集計

結果画面は**レス / スレ / 名前**の3タブ構成です。タップまたは左右スワイプで切り替え、投稿をさまざまな単位で確認できます。

- **レス**：投稿本文、投稿者、日時などを一覧表示。
- **スレ**：取得した投稿をスレッドごとに整理。
- **名前**：投稿者名ごとに整理。
- **集計**：投稿件数、スレ別・名前別の件数、取得できたデータを用いた時間帯グラフを表示。
- **書き込み分析**：エッヂのサイト側が提供する分析結果をアプリ内から確認。

一覧は画面内に多くのレスを表示できるよう調整しています。時間帯グラフは開閉でき、取得できない情報を推測して補完することはありません。

## レス操作・履歴・外部アプリ連携

レスをタップすると、**スレを開く / 全体コピー / 本文コピー / 追加コピー / リンクコピー**の操作を選択できます。結果画面の右上メニューには、検索履歴、ホーム画面に戻る、外部ブラウザで開く、IDコピーなどを配置しています。

検索履歴は直近100件まで保存します。検索結果のお気に入り、並べ替え、個別削除と複数選択削除に対応し、履歴とお気に入りは別々に管理されます。5chの板のお気に入りも保存できます。

スレッドを開く際はChMateとの連携に対応しています。ChMateが使用できない場合は他の対応アプリを検索し、必要に応じてブラウザへ切り替えます。リンクを受け取る側のアプリによって挙動が異なる場合があります。

## 修正・改善

- エッヂで日付とIDが一致しないレスを、選択日の検索結果として表示してしまう問題を修正。
- 5chで検索対象のページがHTTP 404を返したとき、ページが見つからない旨を分かりやすく案内。
- 5chとエッヂの検索結果取得、HTML解析、通信失敗時のエラー表示を改善。
- ChMateや他の対応アプリでのスレッド表示、投稿番号を含むリンクの取り扱いを改善。
- 検索履歴、画面遷移、スクロール、操作ダイアログの表示を調整。
- ダーク / ライト / システムテーマに対応。
- WebViewのローカルファイルアクセスを制限し、アプリの平文HTTP接続を許可する対象をhissi.org関連ホストに限定。

## 動作環境と注意事項

- 対応OS：**Android 8.0（API 26）以降**
- アプリID：`com.chikuwadon.hissidroidplus`
- バージョン：`1.0.0`（versionCode 23）

検索結果の取得は外部サイトの仕様、アクセス制限（HTTP 403など）、通信状況に依存します。hissi.orgの接続互換性のため、暗号化されないHTTP通信を使用する場合があります。本アプリは5ch、エッヂ、hissi.org、ChMateの公式製品ではありません。
