# UI design policy

- Result tabs are **underline-only**: no filled background, outlined pills, or elevated cards.
- The selected tab uses the blue-green accent text and a thin 2dp underline; inactive tabs use subdued gray text.
- Keep the response list dense, separated by thin 1dp dividers rather than large bordered cards.
- Context menus are centered modal dialogs, not bottom sheets or top-aligned popovers.
- Prefer compact typography and readable Japanese over oversized controls.
- Preserve the user-created launcher icon. Do not replace the artwork with unrelated generated assets.

## Edge status

The ChMate/Kyodemo URL syntax is validated, but the live page currently cannot be independently retrieved from the build/research environment. HTTP rejection, verification pages and unsupported HTML layouts are distinguished in diagnostics. No claim is made that Edge native parsing works against live pages.
