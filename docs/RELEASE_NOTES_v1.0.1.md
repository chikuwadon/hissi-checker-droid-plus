# v1.0.1

## ✨ 新機能

- 5chとエッヂのスレッドをChMateおよびHaiagaru版ChMateで開く機能を追加しました。
- ChMateとHaiagaruの両方がインストールされている場合、起動するアプリを選択できるようにしました。
- アプリ選択画面に「次回から確認しない」を追加しました。選択した起動先は5chとエッヂで共通して使用されます。
- ホーム画面のメニューに「スレの開き方」を追加しました。使用するアプリの変更や、毎回選択する設定への切り替えができます。
- レスの長押しによるテキストの範囲選択とコピーに対応しました。

## 🐛 不具合修正

- レスのタップ操作と長押しによるテキスト選択の安定性を改善しました。
- スクロールや画面の再描画後にテキストが選択できなくなる問題を修正しました。
- 外部アプリとの連携処理を見直し、スレッドを開く際の安定性を改善しました。

## 🔧 改善・最適化

- 検索履歴の表示処理を最適化し、スクロール時の負荷を軽減しました。
- エッヂの検索結果取得と書き込み分析の処理を最適化し、画面操作への影響を軽減しました。
- 通信処理とメモリ管理を見直し、動作の安定性を向上させました。
- 不要な内部処理を整理し、アプリ全体のパフォーマンスを改善しました。
