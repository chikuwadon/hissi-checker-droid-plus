# v1.0.2

## ✨ 新機能

- 5chとエッヂの必死チェッカーに「URLをコピー」と「書き込みスレをコピー」を追加しました。
- 書き込みスレのコピーでは、投稿したスレッドの一覧と投稿件数などをまとめてコピーできるようにしました。

## 🐛 不具合修正

- ChMate / Haiagaruのレス長押しからエッヂのID検索を開いた際、検索結果が正しく表示されない問題を修正しました。
- エッヂの必死チェッカーの一部URLを開くとエラーになる問題を修正しました。
- エッヂの一般検索ページなど、ID検索以外のURLがアプリで開かれる問題を修正しました。

## 🔧 改善・最適化

- 外部アプリから受け取ったURLの判定処理を改善し、5chとエッヂの連携を安定化しました。
- 必死チェッカー表示時の右メニューを整理し、「ホーム画面に戻る」「検索履歴」の順に変更しました。
- コピー関連メニューを「URLをコピー」「IDをコピー」「書き込みスレをコピー」「表示中のレスをすべてコピー」の順に統一しました。
