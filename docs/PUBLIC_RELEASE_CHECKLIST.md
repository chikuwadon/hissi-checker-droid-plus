## 特に確認が必要な点

**原作のアイコンや素材をそのままPublicに含めてよいかは、現在のリポジトリだけからは確認できません。** 画像の著作権、ソースコードの複製・翻案の有無、板一覧データの取得元が確定するまで、ライセンスを勝手に付与しないでください。

**Public化とライセンス付与は別操作です。** LICENSEのないPublicリポジトリは一般的なオープンソースの再利用許諾を与えません。

**デバッグ署名のまま配布を続けるか、正式リリース用に鍵を切り替えるか**は、既存ユーザーの上書き更新可否とデータ保全に直接影響します。鍵を変える際は事前の移行方針が必要です。
