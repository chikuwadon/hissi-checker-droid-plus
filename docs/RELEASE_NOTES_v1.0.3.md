# v1.0.3

## ✨ 新機能

- **ChMate / HaiagaruからのID検索に対応**
  - ChMateのカスタムURL機能を使用して、ID長押しから必死チェッカーdroid+を直接起動できるようになりました。
  - 5chでは直近7日間、エッヂでは日付指定なしでIDを検索します。
  - 日付を指定した検索にも対応しています。

## 🔧 改善

- アプリ全体をJavaからKotlinへ移行し、既存機能の動作を維持しながら内部コードを刷新しました。

## 🔗 ChMate連携の設定

ChMateのカスタムURLに以下を登録してください。

```text
必死チェッカーdroid+ hissi:{$host}/{$bbs}/{$Iid}
```

これにより、ChMateからID検索を直接呼び出せます。
