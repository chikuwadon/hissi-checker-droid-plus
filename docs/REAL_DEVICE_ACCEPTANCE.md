# v1.0.0 Android 実機検証

Android 8／14／16の実機を対象に、ADB補助計測と手動操作で確認します。エミュレーターの合格は実機確認の代わりになりません。

## Windows 11 + ADB

PowerShellで、既にインストール済みの端末を測定します。

~~~powershell
.\tools\adb_real_device_check.ps1
~~~

複数端末の場合は -Serial にADB端末番号を渡します。更新を実際に行う場合だけ、次の引数を使います（アンインストールはしません）。

~~~powershell
.\tools\adb_real_device_check.ps1 -InstallCandidate -ApkPath ".\HissiCheckerDroidPlus-v1.0.0.apk"
~~~

取得するのは端末API、バージョン、起動時間とメモリの概要のみ。ID、Cookie、通信本文は取得・送信しません。結果はローカルファイルに保存します。

- [ ] 履歴、お気に入り、個別／複数削除、ソート
