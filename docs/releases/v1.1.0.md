# 必死チェッカーdroid + v1.1.0

画面構成の刷新、過去ログ検索機能の追加、検索履歴の拡充、内部処理の近代化を行った大型アップデートです

## ✨ 新機能

- 下部ナビゲーションバーを導入
  - ホーム・結果・過去ログ・履歴・お気に入り・設定を簡単に切り替え可能
  - ナビゲーションバーの表示項目をカスタマイズ可能
- 過去ログ検索機能を追加
  - エッヂの過去ログ（3代目）
  - Kyodemo / エッヂ
  - Kyodemo / 5ch
  - ぬこ / 5ch
- 過去ログの検索結果をアプリ内で表示
- 過去ログ検索にサービス別の詳細条件、ページ指定、検索キーワード履歴を追加
- 過去ログ検索欄を画面上部または下部に配置できる設定を追加
- 過去ログ検索結果の文字サイズをリアルタイムで調整できる機能を追加（70～160%、5%単位）
  - スレタイ・日時・レス数・行の高さが文字サイズに連動
  - 調整した文字サイズをアプリ再起動後も保持
- 最後に選択した検索サービスと板をアプリ再起動後も保持
- 過去ログ検索結果の長押しによるスレタイ・URLのコピーに対応
- ホーム画面と過去ログ検索の板選択ダイアログに検索機能を追加
- ホーム画面と過去ログ検索で板のお気に入りを共有
- 検索履歴の保存件数を100～10,000件（100件単位）または無制限に設定可能
- 履歴・お気に入りに板名・ID・日付による絞り込み機能を追加

## 🐛 不具合修正

- ChMateなどの外部アプリとの連携時における戻る操作を修正
- 過去ログ検索結果から元の5ch・エッヂのスレッドを開けるよう修正
- 過去ログ検索結果のURLコピーを元スレッドのURLに統一
- ぬこの検索結果を正常に取得できない問題を修正
- 検索欄を画面下部に配置した際にキーボードで隠れる問題を修正
- タブ切り替え時のキーボード表示制御を改善
- 履歴・お気に入りの更新中に古いデータを操作できる問題を修正
- WebViewの画面破棄後に遅延処理が実行される問題を修正

## 🔧 改善・最適化

- AndroidXを活用した画面管理・ライフサイクル管理への移行
- タブ切り替え時の画面状態保持を改善
- 検索結果の集計・解析・描画処理を最適化
- 履歴・お気に入りのデータベース読み込み・並べ替え処理を最適化
- HTML解析・HTTP通信・時間帯別投稿グラフの処理を最適化
- 過去ログ検索のページキャッシュによる再取得処理の削減
- 履歴・お気に入りの一覧表示をコンパクト化
- 過去ログ検索画面と設定画面のアプリバーを廃止し、表示領域を拡大
- UI・ダイアログ・各種表記の統一
- 旧式Android APIの近代化と不要なコードの整理
- 外部URL・インテント・WebViewのセキュリティを強化
- 開発環境および依存ライブラリを更新
- 全体的な安定性・パフォーマンスを改善
